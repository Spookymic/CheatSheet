## Utilisation

Chaque fichier est autonome et au format Markdown, consultable dans n'importe quel éditeur ou sur GitHub/GitLab. Recherchez avec `Ctrl+F` pour trouver une commande rapidement.

## Personnalisation des shells et éditeurs

Les fiches suivantes contiennent une section dédiée à la personnalisation via les fichiers de configuration :

- **Vim** → `~/.vimrc` (options, mappings, plugins avec vim-plug)
- **Bash** → `~/.bashrc` / `~/.bash_profile` / `~/.inputrc`
- **Zsh** → `~/.zshrc` (options, prompt, complétion, oh-my-zsh)
- **Shell** → où placer chaque type de configuration (login vs interactif)
- **PowerShell** → `$PROFILE` (alias, fonctions, prompt, PSReadLine)
