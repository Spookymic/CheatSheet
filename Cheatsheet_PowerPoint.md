# Cheatsheet PowerPoint

## Raccourcis clavier
| Raccourci | Effet |
|---|---|
| `Ctrl+M` | nouvelle diapositive |
| `Ctrl+D` | dupliquer la diapositive / l'élément |
| `Ctrl+Shift+D` | dupliquer l'élément |
| `Ctrl+G` | grouper les éléments |
| `Ctrl+Shift+G` | dissocier |
| `Ctrl+Shift+H` | afficher/masquer les guides |
| `Ctrl+C` / `Ctrl+V` | copier / coller |
| `Ctrl+X` | couper |
| `F5` | lancer le diaporama depuis le début |
| `Shift+F5` | lancer depuis la diapositive courante |
| `Échap` | quitter le diaporama |
| `Ctrl+P` | annoter pendant le diaporama (stylo) |
| `Ctrl+I` | pointeur laser pendant le diaporama |
| `B` / `.` | écran noir pendant le diaporama |
| `W` / `,` | écran blanc pendant le diaporama |
| `S` | arrêter / reprendre la lecture |
| `Ctrl+S` | enregistrer |
| `Alt+F5` | diaporama avec le présentateur (test) |
| `Ctrl+Z` / `Ctrl+Y` | annuler / rétablir |

## Navigation dans le diaporama
| Touche | Effet |
|---|---|
| `Flèche droite` / `Bas` / `Entrée` / `Espace` | diapositive suivante |
| `Flèche gauche` / `Haut` / `Retour arrière` | diapositive précédente |
| `Numéro + Entrée` | aller à la diapositive N |
| `Ctrl+L` | écran noir avec retrait du pointeur |

## Création et gestion des diapositives
| Action | Comment |
|---|---|
| Nouvelle diapositive | `Ctrl+M` ou clic droit → `Nouvelle diapositive` |
| Changer la disposition | `Accueil` → `Disposition` |
| Réorganiser | glisser-déposer dans le volet des vignettes |
| Masquer une diapositive | clic droit → `Masquer la diapositive` |
| Dupliquer | clic droit → `Dupliquer la diapositive` ou `Ctrl+D` |
| Supprimer | `Suppr` |

## Diaporama
| Action | Comment |
|---|---|
| Transitions | onglet `Transitions` (appliquer à une ou toutes les diapositives) |
| Durée et déclenchement | `Transitions` → durée / au clic ou automatique |
| Animations | onglet `Animations` (Entrée, Accentuation, Sortie, Trajectoire) |
| Panneau Animation | `Animations` → `Panneau Animation` |
| Répéter une animation | `Panneau Animation` → `Déclencheur` |
| Minutage automatique | onglet `Diaporama` → `Répétitions` |
| Mode présentateur | `Diaporama` → `Mode présentateur` |
| Configurer le diaporama | `Diaporama` → `Configurer le diaporama` (boucle, moniteur...) |

## Thèmes et modèle
| Action | Comment |
|---|---|
| Appliquer un thème | `Conception` → choisir un thème |
| Variantes de couleurs | `Conception` → `Variantes` |

## Astuces pro
| Astuce | Détail |
|---|---|
| Règle 6×6 | max 6 puces × 6 mots par diapositive |
| Couleurs du thème | rester sur les couleurs du thème pour une cohérence |
| Guides intelligents | les guides apparaissent automatiquement à l'alignement |
| Touche `Alt` | alignement temporaire sur les guides (sans aimantation) |
| Changer la langue | `Révision` → `Langue` |
| Export PDF | `Fichier` → `Exporter` → `Créer un document PDF/XPS` |
| Compression d'images | `Format` → `Compresser les images` |
| Présentation en ligne | `Diaporama` → `Présenter en ligne` (Teams/Web) |

## Dépannage rapide
| Problème | Solution |
|---|---|
| Vidéo ne lit pas | vérifier le codec / `.mp4` avec H.264 |
| Police manquante sur autre PC | `Fichier` → `Options` → `Enregistrement` → `Incorporer les polices` |
| Images floues | insérer en haute résolution, ne pas zoomer au-delà de 100 % |
| Diaporama saccadé | vérifier la transition (desactiver `Exécuter en continu`) et la taille du fichier |
