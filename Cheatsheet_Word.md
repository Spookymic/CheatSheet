# Cheatsheet Word

| Raccourci | Effet |
|---|---|
| `Ctrl+N` | nouveau document |
| `Ctrl+O` | ouvrir |
| `Ctrl+S` | enregistrer |
| `Ctrl+Shift+S` | enregistrer sous |
| `Ctrl+P` | imprimer |
| `Ctrl+Z` / `Ctrl+Y` | annuler / rétablir |
| `Ctrl+F` / `Ctrl+H` | rechercher / remplacer |
| `Ctrl+A` | tout sélectionner |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | couper / copier / coller |
| `Ctrl+Z` | annuler |
| `F12` | enregistrer sous |

## Styles
| Action | Comment |
|---|---|
| Appliquer un style | Ruban `Accueil` → groupe `Styles` |
| Créer un style | Sélectionner le texte → clic droit → `Styles` → `Créer un style` |
| Modifier un style | Clic droit sur le style → `Modifier` |
| Nettoyer le formatage | `Ctrl+Espace` (police) / `Ctrl+Q` (paragraphe) / bouton `Effacer la mise en forme` |

|---|---|

## Astuces
- **Mode sans distraction** : `Alt+W, F` ou affichage `Lecture`.
- **Raccourci pour créer un tableau** : `Insertion` → `Tableau` → `Tableau rapide`.
- **Déplacer un paragraphe** : sélectionner puis `Maj+Alt+↑` / `Maj+Alt+↓`.
- **Pomme de pagination** : double-clic sur le `P` (¶) dans le ruban pour l'afficher/masquer les marques de formatage `Ctrl+Shift+8`.
- **Texte en colonnes** : `Mise en page` → `Colonnes`.
- **Mot de passe de protection** : `Fichier` → `Informations` → `Protéger le document`.
